# MarkEase

AI-Powered Attendance Management System built using Face Recognition, Voice Recognition, Streamlit, and Supabase.

## Features

- Teacher & Student Authentication
- Face Recognition Attendance
- Voice Attendance Verification
- Subject Management
- Student Enrollment
- Attendance Tracking & Analytics
- Supabase Database Integration

## Tech Stack

- Python
- Streamlit
- Supabase
- Face Recognition
- Dlib
- Resemblyzer
- NumPy
- Pandas
- Scikit-Learn

## Installation

```bash
git clone https://github.com/Gopal1909/markease-ai-attendance.git
cd markease-ai-attendance
pip install -r requirements.txt
streamlit run app.py
```
